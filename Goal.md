# Spelling Correction Tool

## Targets

- [ ] Parse training data to create a word frequency table.
- [ ] Create a trie with all possible words from the word frequency table.
- [ ] From taking in a string, generate a list of possible corrections 1 edit away.
- [ ] From a string, generate a list of possible corrections 2 Levenshtein distance away.
- [ ] Use the word frequency table to score the possible corrections.
- [ ] Return the highest scoring correction.

## Inputs

1. Training data
2. String to correct

## Outputs

1. Corrected string
