# [Spelling Correction Tool](https://codingchallenges.substack.com/i/174025320/coding-challenge-spelling-correction-tool)

## Challenge Instructions

In this challenge, I will be building a spelling correction tool that will suggest spelling corrections for given words.

## Scope and Limitations

- The spelling correction tool will be written in C#
- The spelling correction tool will just be a console application
- The spelling correction tool will use frequency data from a single text file
